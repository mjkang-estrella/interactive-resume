Finding the first 1,000 API users

I launched integrations and developer incentive programs to help people try Liner in the tools they already used. Together, this work acquired the first 1,000 active API users.

Give people a useful first task

An API documentation page assumes the visitor already has something to build. Integrations offered another starting point: search for a source, research a company, or answer a question inside an existing workflow.

My integration work included Liner's Model Context Protocol connection for AI assistants and its Zapier integration. The MCP connection exposed web and scholarly search, cited answers, and research tools to compatible assistants. Zapier brought those actions into app-to-app workflows.

Show how it fits into everyday work

The integration materials included concrete examples: a Gmail message becoming a research brief in Google Docs, a new spreadsheet lead receiving company research, and a calendar event triggering meeting preparation.

Setup instructions and examples helped developers get to a first useful request. Developer and startup incentive programs ran alongside the integrations to encourage trial.

Result

Together, the integrations and incentive programs acquired the first 1,000 active API users.
