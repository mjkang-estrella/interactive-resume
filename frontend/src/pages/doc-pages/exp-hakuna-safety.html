Better review tools for AI moderation

I improved the labeling workflow and monitoring dashboards for Hakuna's moderation team. Detection accuracy increased 30%, and review latency fell 50%.

The model learned from inconsistent labels

Hakuna's safety model screened screenshots captured from live broadcasts every second or when users filed reports. Human reviewers checked its decisions, and those labels fed back into training.

Working with the AI/ML team, we found errors in the human-labeled data. Reviewer interviews and workflow observations pointed to the admin interface: people lacked clear frame sequences, report context, and confidence information when making decisions.

Give reviewers the context they need

We rebuilt the panel to show frame sequences and metadata, clarified action buttons, and added keyboard shortcuts. I also wrote labeling guidelines and onboarding documentation so reviewers could apply the same criteria across shifts.

With the data and AI/ML teams, I built dashboards for detection accuracy, review latency, and labeling consistency. Moderation and AI/ML teams used them for daily monitoring.

Result

Detection accuracy improved 30%, and review latency fell 50%.
