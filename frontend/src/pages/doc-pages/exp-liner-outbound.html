AI-Assisted Outbound

Context

Beyond self-serve growth, Liner’s AI search API also needed an enterprise pipeline. Researching each prospect and preparing outreach by hand does not scale to a large account list.

Approach

I built an AI-assisted system for prospect research and outbound preparation and ran it across 1,200 accounts, so outreach could start from researched, account-specific context instead of a blank page.

Result

  • Contributed to an enterprise win.
  • Built $400K in qualified ARR pipeline.
