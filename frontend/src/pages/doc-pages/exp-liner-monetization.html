API Growth & Monetization

Context

Liner is a Series C AI search agent startup. As the MBA product manager intern for API Growth & Monetization (May–Aug 2026), I owned growth and monetization for Liner’s AI search API, the developer-facing side of the product.

Approach

I redesigned the acquisition-to-purchase journey, the path a developer takes from the landing page to becoming a paying customer:

  1. Interactive product comparisons: let developers see the difference for themselves while evaluating, rather than reading claims.
  2. Bonus credits for adding a card: gave developers a reason to add a payment method early, shortening the path to first paid usage.

Result

Landing-to-paid conversion tripled.
